# Indeks over dokumentasjonen

Les denne først, så bare dokumentet for systemet du skal endre, og `docs/BACKLOG.md` (over lesevaktens grense: «Spillarbeid som venter» øverst med `offset` og `limit`, resten med `grep`). Dokumentene i `docs/systemer/` er overleveringen delt opp per system 26.10.2026 (`docs/utviklingsplan.md`, fase A); overskriftene har de gamle kapittelnumrene, og `docs/systemer/gamle-numre.md` sier hvor hvert nummer havnet. Nytt skrives inn i systemdokumentet samme dag som det avgjøres.
