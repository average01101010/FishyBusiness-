# Steg 78, L1e: CSP for spillet (11.11.2026)

På `test.detstorebla.no` (versjon 9d31f1922cc3 eller nyere). Ingenting skal se annerledes ut; det som prøves, er at ingenting er stoppet.

1. **Logg inn** med kontoen din (Innstillinger → Konto, eller «Registrer meg» som gjest). Du skal komme til WorkOS og tilbake til spillet som innlogget. Økta fikk ikke prøvd dette: nettet dens når ikke WorkOS og testprosjektet.
2. **Spill fem minutter:** kast loss, åpne kartplotteren, telefonens apper, Tilbakemelding med et bilde, Malerverkstedet med en egen logo. Lyd på.
3. **Se i admin → Feil** etter linjer som begynner med `csp:`. Finnes det noen, er noe stoppet som ikke skulle vært det: si fra med linja.

Det du må gjøre uansett (`docs/planer/lansering-plan.md` kap. 5): punkt 12, kortere økter hos WorkOS, og punkt 14, `setup.sh` på serveren på nytt.
