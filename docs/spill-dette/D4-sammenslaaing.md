# D4: se på telefonen (stående) og nettbrettet

På testadressen. Telefonen stående først.

1. **Om bord:** fanene er Redskap, Last, Mannskap og drift, Båten. Velg rigg i Redskap (ett kort øverst). Finner du det du pleide å finne under Rigg og Lasterom?
2. **Utstyrsbutikken:** Service er tredje fane. Kjøp og monter noe: «Arbeid på båten» skal stå øverst med nedtelling. Har du flere båter, åpner butikken på den som ligger ved kaia.
3. **Oppdrag:** samme side fra Bygd, fra mottaket og fra telefonen, med Turer, Bestillinger og Kappløp. Omdømmet står under de nye bestillingene.
4. **Bygd › Ansett** åpner Mannskapsbørsen. De som er mønstret på, står bak «Ansatte» i Om bord › Mannskap og drift.
5. **Kystbanken › Regnskap:** konto, gjeld og resultat først, resten under «Detaljer». Er de tre tallene de du vil se først?
6. **Dekksdagboka:** bare Dagbok og Salg. Er skriften stor nok nå?
7. **Liggende på nettbrettet:** skuffen er like bred på alle sidene. Bedre, eller for bred på banken og Om bord?
