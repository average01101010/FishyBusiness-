# Steg 18b: Driftsplan 2 med garn og deg alene om bord

- **Hvor:** en båt med garnhaler (for eksempel havsjarken), deg om bord og ingen fra mannskapet med, i havn.
- **Gjør:** lag en garnplan under Driftsplan og start den.
- **Skal skje:** planen går ikke ut. Den sier «Garn krever minst to om bord: deg og én til. Planen venter til det er to om bord.» Ansett én eller ta med én fra mannskapet, så går den ved neste time. Før gikk den ut og fikk ikke trukket garna.
- **Ellers:** ingenting annet skal se annerledes ut på Driftsplan-siden eller i Rederi.
