# Steg 21c Ø3d: modellene som typede tabeller (10.11.2026, versjon 6b56a587a16f på detstorebla.no)

- Hvor som helst, gjerne ved kaia i Finnsnes eller en havn med andre båter: se på din egen båt nært og fjernt, og på havneanlegget. Alt skal se ut som før (samme båt, samme farger, motoren og rorkulten på plass).
- Malerverkstedet på snekka, den nye hurtigsjarken, snøkrabbebåten eller ringnotbåten med et design (stripe under ripa, tofarget, vannlinje): linjene helt akter ved hekken kan ha flyttet seg noen centimeter; ellers like.
- Spill 15–20 minutter som vanlig: spillet skal ikke henge eller krasje oftere enn før. Minnet står i feilrapportene i admin (`js_mb`); etter starten skal det være rundt en firedel lavere enn før (376 → 281 MB i testmaskinen).
