# Steg 33d: skjermbildene

Hvert bilde har seks ruter: øverst nord (Tromsø), øst (Bodø), sør (Bergen); nederst vest (Kristiansand), lateral (Hammerfest, en babordbøye og en fast babordstake), isolert fare (Tromsø). `for_*` er bygget før K3 (koden før og `sjomerker-7`), `etter_*` er K3 med `sjomerker-8`. Liggende 1280×800, stående 800×1280. Laget med `tests/merkeshot.py`. (I den første ruta står stripa fortsatt med Finnsnes: spillets klokke holdes mens bildet tas.)
