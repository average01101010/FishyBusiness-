Det Store Blå har flyttet

Spillet ligger nå på detstorebla.no. Denne adressen oppdateres ikke lenger.

Ta med spillet ditt

  1. Trykk «Kopier lagringen».
  2. Åpne detstorebla.no og start spillet.
  3. Åpne telefonen i spillet → Innstillinger → Lagret spill → «Lim inn lagring», lim inn koden og trykk «Last inn dette spillet».
Gå til detstorebla.no

Lagringen på denne adressen blir liggende i nettleseren din. Ingenting slettes her.
